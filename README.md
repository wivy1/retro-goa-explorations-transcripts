# DJ Solitare's Retro Goa Explorations Transcripts

This repository contains transcripts of each episode of [DJ Solitare's Retro Goa Explorations](https://www.youtube.com/playlist?list=PLI3nfsMvaXNhckzdkb0KJDu-nPeLlpw-0).

The archive was created because DJ Solitare's contemporaneous involvement in the 1990s Goa trance scene, together with his close personal connections from that time, provides insider and behind-the-scenes details about these tracks and their production that are not catalogued elsewhere.

Pull requests correcting any errors are welcome.

Transcripts for future episodes will be added in bulk.
