# DJ Solitare's Retro Goa Explorations Transcripts

This repository contains cleaned transcripts of every episode of [DJ Solitare's Retro Goa Explorations](https://www.youtube.com/playlist?list=PLI3nfsMvaXNhckzdkb0KJDu-nPeLlpw-0) video series.

This archive was created because DJ Solitare's direct involvement in the 1990s goa trance scene, along with his close personal connections from that time, gives him insider details about these tracks and their production that have note been documented elsewhere.

Pull requests correcting any errors are welcome.
